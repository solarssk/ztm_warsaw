# 1.2.1: Marketplace and Home Assistant 2026.11

Home Assistant 2026.11 replaces HACS with the built-in **Marketplace**. This small release updates the installation instructions and adds a check of the integration's basic operation on the new Core.

## 🔄 Updating

Update the integration through Marketplace or HACS and **restart Home Assistant**. You do not need to configure your lines or stops again. The minimum supported version remains **Home Assistant 2026.1**.

If you already use HACS, Home Assistant automatically transfers your installed repositories and their updates to Marketplace when you upgrade to 2026.11.

## ✨ What's changed

- **Instructions for Marketplace and HACS**: the README in all eight languages and the wiki cover installation on newer and older Home Assistant versions.
- **An operation check on HA 2026.11.0**: an automated test configures a line, fetches a timetable from a local simulation of the City's API, checks the sensor and unloads the integration.
- **Updated project tools**: refreshed dependencies used to check the code and prepare releases.

The full test suite passed on HA 2026.1 and 2026.10.4. On 2026.11.0 we checked the basic scenario described above; running the full suite on that version still needs an update to the test tooling.
