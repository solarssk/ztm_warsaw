# 📦 Installation

Requires Home Assistant **2026.1 or newer**.

## With Marketplace (Home Assistant 2026.11 or newer)

1. Open **Settings → Marketplace**.
2. Search for **Warsaw Public Transport** and install it.
3. Continue with [Configuration](1.-Configuration). Restart Home Assistant if prompted.

When you upgrade Home Assistant from an older version, Marketplace automatically takes over the repositories and updates installed through HACS. You do not need to reinstall the integration.

## With HACS (Home Assistant 2026.1–2026.10)

1. In Home Assistant open **HACS**.
2. Search for **Warsaw Public Transport**.
3. Choose **Download** and confirm.
4. **Restart Home Assistant.**

A new version appears in Marketplace and HACS when a GitHub Release is published. A beta (for example `1.2.0b5`) is published as a pre-release; both offer it only if you turn on *Show beta versions* for the repository.

## Manually

1. Download the latest version from the [GitHub Releases](https://github.com/solarssk/ztm_warsaw/releases).
2. Copy the `ztm_warsaw` folder from the archive to `/config/custom_components/`.
3. Restart Home Assistant.

## Updating

Update through Marketplace (Home Assistant 2026.11+) or HACS (older versions) and **restart Home Assistant**. Your entries keep working; nothing needs to be set up again. If a version needs something from you, its entry in the [CHANGELOG](https://github.com/solarssk/ztm_warsaw/blob/main/CHANGELOG.md) starts with an **Adopter action** list.

**Why the restart?** Home Assistant reads the code of an integration only when it starts, so reloading the integration does not load a new version. Every custom integration needs the restart after an update; the integration cannot avoid it.
